# Huang / Kysar Single Crystal UMAT — Provenance

This folder is **not** a git repository. Files were downloaded manually.

## Source
- Original page: http://www.columbia.edu/~jk2079/Kysar_Research_Laboratory/Single_Crystal_UMAT.html
  (the live Columbia Kysar Lab site has since moved / removed this page)
- Retrieved via the Internet Archive Wayback Machine snapshot `20210219050056`
  from base URL `http://www.columbia.edu/~jk2079/fem/`

## Files
| File | Original name | Description |
|------|---------------|-------------|
| `umatcrystal_mod.f` | `umatcrystal_mod.f` | The single-crystal plasticity UMAT Fortran source |

## Attribution / citation
- Huang, Y. (1991). "A user-material subroutine incorporating single crystal
  plasticity in the ABAQUS finite element program, Mech Report 178", Division of
  Engineering and Applied Sciences, Harvard University, Cambridge, MA.
- Kysar, J. W. (1997). "Addendum to 'A user-material subroutine incorporating
  single crystal plasticity in the ABAQUS finite element program, Mech Report 178'".
